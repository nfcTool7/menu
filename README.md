# NFC-меню: бесплатно, без бота и сервера

Что здесь:
- `index.html` — само меню. Открывается по ссылке вида `https://ваш-сайт/?v=код`.
- `builder.html` — конструктор. Вы заполняете форму, справа сразу видите меню, потом скачиваете файл настроек заведения.
- `venues/` — папка с файлами заведений (по одному `код.json` на заведение). Там уже лежит демо `demo.json`.
- `menu.css`, `menu.js` — дизайн и логика, их трогать не нужно.

## 1. Один раз: выкладываем сайт бесплатно (GitHub Pages)

1. Зарегистрируйтесь на github.com (бесплатно).
2. Нажмите **New repository**, назовите, например, `menu`, выберите **Public**, создайте.
3. В репозитории: **Add file → Upload files**, перетащите все файлы и папку `venues`, нажмите **Commit changes**.
4. **Settings → Pages**: в Branch выберите `main` и папку `/ (root)`, нажмите Save.
5. Через 1-2 минуты сайт будет по адресу `https://ваш-ник.github.io/menu/`. Проверьте демо: `https://ваш-ник.github.io/menu/?v=demo`

(Альтернативы тоже бесплатные: Cloudflare Pages и Netlify.)

## 2. Для каждого нового заведения

1. Откройте `https://ваш-ник.github.io/menu/builder.html`.
2. Впишите адрес сайта (один раз, он запомнится), заполните поля, выберите тему.
3. Нажмите **Скачать файл меню** (скачается `код.json`).
4. В репозитории откройте папку `venues` → **Add file → Upload files** → загрузите этот файл → Commit.
5. Нажмите **Скопировать ссылку для NFC** и запишите ее в чип в вашем приложении. Через минуту меню работает.

## 3. Как изменить меню позже

В конструкторе выберите существующий файл в самом верху («Файл существующего меню»), поправьте, скачайте и загрузите в `venues` с тем же именем (заменит старый).

## Важно

- Ссылка короткая (около 50 символов), в чип NTAG213 она помещается.
- Пустое поле = кнопка не показывается.
- Репозиторий публичный, поэтому файлы заведений (включая пароль Wi-Fi) может открыть любой, кто знает или угадает адрес. Пароль Wi-Fi и так показывается всем гостям, но личных данных в файлы не пишите.
- Если открыть `index.html` двойным кликом с компьютера, меню не загрузится (браузер блокирует чтение файлов). Смотреть нужно уже на сайте.
